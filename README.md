# 我和我 · The Tides Within Me

一本可以真的「翻」的电子绘本。

页面上的每一个像素都是一张画，**全站零文字** —— 没有标题、没有说明、没有页码，所有信息由图像、动效和光色承担。书在加载时是合上的，只露出封面和书脊；用手一拨，它才会摊开。

- 在线预览：<https://over-c100.github.io/The-Tides-Within-Me/>
- 作者：**香菜洗衣机**
- 技术：Mesh Gradient + Glassmorphism + CSS 3D 书页卷曲

---

## 怎么翻

| 操作 | 效果 |
| --- | --- |
| 在右页向左拖 | 往后翻（拖过约 1/3 就会翻过去，不够则回弹） |
| 在左页向右拖 | 往前翻 |
| 鼠标悬停 | 书页有随光斑移动的高光，书本微微抬起 |
| 左下 / 右下箭头 | 上一页 / 下一页 |
| 底部雨滴进度条 | 直接跳到任意一页；雨滴数量 = 书页数 |
| 手机竖屏 | 会出现「请把手机横过来」的图形提示 |

拖动和点击走的是同一套书页状态机，落定后的画面完全一致。

## 这本书长什么样

- **环境光**：五团色斑在背景里缓慢漂移，叠加方式为 `screen`，颜色由当前书页的主色推算 —— 翻页时整个房间的色调跟着换。色值用 `@property` 注册为 `<color>`，所以过渡是连续插值的，而不是硬切。
- **玻璃质感**：控件、光斑、雨丝都带 `backdrop-filter` 的模糊与饱和、内侧高光和一层斜向光油；雨一直下，速度随机。
- **书的厚度**：合上时能看到白色内页的叠层和书脊的平行四边形书腰；摊开时书脊凹槽、内页阴影、右侧页堆依次就位。这些全部由布局合成，图里并没有画。
- **卷曲的那一页**：不是贴图拉伸，而是把一页切成 18 条竖向条带，逐条绕书脊旋转、逐条做明暗渐变，拼出一条连续的圆柱面。翻动时书页真的会「鼓」起来。
- **预加载**：18 张整幅画先下载完再开始，加载条走满才亮书，翻页不会等图。

## 书页

```
cover          封面
00-flyleaf     环衬
01-02 … 31-32  十六个跨页
```

共 18 张 4144×1465 的整幅插画（封面也在其中），按跨页切开贴在左右两页上。

## 目录结构

```
index.html            入口：书、控件、进纸层、雨
assets/
  style.css           书的几何、卷曲、玻璃质感、网格渐变
  book.js             状态机：翻页、拖拽、卷曲、配色、雨滴进度
  bookdata.js         18 页的主色与情绪，供环境光取色
  ph.css              图片占位骨架
  images/             18 张整页插画（含封面）
.nojekyll             让 GitHub Pages 原样发布
README.md             你正在看的这份
```

## 本地跑

不需要构建、不需要依赖，任何静态服务器都行：

```bash
python -m http.server 8080
# 然后打开 http://127.0.0.1:8080/
```

直接双击 `index.html` 也能看，但 `file://` 下部分浏览器的滤镜与 3D 表现会打折，建议起个服务器。

## 兼容

Chrome / Edge / Safari 最新版。用到了 `@property`、`backdrop-filter`、`transform-style: preserve-3d`，老浏览器会降级成「能翻但没卷曲」。
